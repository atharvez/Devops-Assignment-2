# DevOps Assignment 2

University DevOps coursework -- Assignment 2: GitHub Actions CI/CD with Node.js.

## Topics Covered

- GitHub Actions workflow design
- Automated unit and integration testing
- Docker multi-stage builds
- Environment-based deployment (dev/staging/prod)

## Pipeline Flow

```
Push -> Lint -> Test -> Build Docker Image -> Deploy
```

## Getting Started

```bash
git clone https://github.com/atharvez/Devops-Assignment-2.git
cd Devops-Assignment-2
npm install
npm test
npm start
```
